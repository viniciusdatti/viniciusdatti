## Engineering Focus

A maior parte do meu trabalho envolve sistemas onde o dado muda constantemente e a interface precisa acompanhar sem degradar.

Na Superior Industries (fev/2023 – mai/2026) construí e mantive dashboards de monitoramento industrial que consumiam streams contínuos de telemetria via WebSocket — sensores de temperatura, pressão, vibração e rotação com validação dinâmica de thresholds e múltiplos estados de alerta. O problema recorrente nesses sistemas é manter a UI coerente quando o servidor manda dado mais rápido do que o usuário consegue processar; parte relevante do trabalho foi resolver isso com throttling no cliente e renderização condicional por prioridade de dado.

Além do produto, fui responsável pela evolução do design system interno: componentes documentados via Storybook, padrões de composição e revisão de código com foco em consistência visual e previsibilidade de comportamento.
